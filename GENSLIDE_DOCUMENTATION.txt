SECTION 1: EXECUTIVE SUMMARY & SYSTEM PURPOSE
====================================================================================================

GenSlide is an enterprise-grade desktop presentation software application designed for voice-driven 
slide control, real-time slide content editing, and dual-screen HDMI display projection.

Key System Capabilities:
----------------------------------------------------------------------------------------------------
  • Zero-Latency Voice Keyword Triggering : Sub-10ms local acoustic decoding (Vosk Kaldi) + Google API.
  • Dual-Screen HDMI Auto-Targeting       : 100% borderless fullscreen on projectors (Monitor #2),
                                            compact 740x416 control preview on laptop screen (Monitor #1).
  • 100% PowerPoint COM Visual Exporter   : High-definition visual exports (.png/.jpg) preserving 100% of
                                            native typography, tables, and graphics via pywin32.
  • Live Editable Keyword Matrix          : Real-time keyword editing with instant engine re-indexing.
  • Portable USB Standalone (.exe)        : Single self-contained 111MB executable for USB execution.

SECTION 6: REAL-TIME DATA PIPELINES & WORKFLOWS
====================================================================================================

1. Audio Capture & Resampling Subsystem (<1ms):
   Microphone PCM audio captured via SoundDevice -> Vectorized mono downmixing & 
   linear interpolation resampling (numpy.interp) converting 44.1kHz to 16kHz Int16.

2. Offline Vosk Acoustic Neural Decoding (<10ms):
   Resampled 16kHz PCM stream pushed to audio queue -> vosk_instant_worker_loop thread -> 
   AcceptWaveform -> PartialResult returns recognized text in real-time milliseconds.

3. Fuzzy Word-Boundary Keyword Matcher:
   Spoken text normalized -> Matched against keywords sorted by length using 
   r'\b' + re.escape(kw) + r'\b' -> Triggers slide jump callback.

4. 100% PowerPoint COM Visual Exporter:
   SlideManager loads .pptx -> win32com.client COM interface exports 100% color-accurate 
   PNG slide images -> PIL loads images onto GUI canvas.

5. HDMI Multi-Monitor Auto-Targeting:
   screeninfo queries physical monitors -> Projectors (Monitor #2) display 100% borderless 
   fullscreen (overrideredirect) -> Laptop screen shows compact 740x416 window preview.
